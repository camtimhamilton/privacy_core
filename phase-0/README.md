# Фаза 0 — аудит

**Срок по плану:** 1–2 недели
**Статус:** в работе
**Цель:** не изобретать заново и не повторять чужих ошибок.

Фаза заканчивается решениями, а не текстом «мы всё изучили». Критерий выхода — четыре предмета:

1. документ «что берём, что отвергаем и почему»;
2. разбор слабых мест существующих решений с таблицей пробелов по русскому языку;
3. черновик протокола бенчмарка с номером версии;
4. решение go/no-go по модулю контекстных утечек.

## Метод

Каждое утверждение в документах фазы 0 снабжается ссылкой на источник. Утверждения разделяются на три категории:

- **проверено** — источник открыт, факт подтверждён;
- **по аннотации** — известно только из описания или вторичного пересказа;
- **не проверено** — не подтверждено ничем.

Числа приводятся с указанием метода и данных, на которых получены. Если работа заявляет метрику, но не публикует протокол её измерения, это фиксируется как отдельный факт, потому что сравнить такое число с нашим нельзя.
