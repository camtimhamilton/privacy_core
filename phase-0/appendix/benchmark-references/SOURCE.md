# Откуда эти файлы

Опубликованные результаты бенчмарка `test-3` проекта
[SurrogateShield](https://github.com/sherwinvishesh/SurrogateShield) (Apache-2.0),
скачанные из ветки `main` 16.10.2025 для использования как эталонный ориентир.

| Файл | Что содержит | Источник |
|---|---|---|
| `realdata_test3.json` | Полные результаты по 7 «рукам» | `bench/results/realdata_test3.json` |
| `perf_arms_v4.json` | Замеры скорости и памяти | `bench/results/perf_arms_v4.json` |
| `verdict_test3.json` | Сводный вердикт по проверкам | `bench/results/verdict_test3.json` |
| `results-README.md` | Описание: команды, коммиты, хэши | `bench/results/README.md` |

Заморозка набора по данным самих файлов: `freeze_sha256 = 31d87c099d6ca519…`,
коммит `8d4ea8b3a49caa1fa8f525adb342edf403b6ae8c`.

**Зачем храним.** В фазе 4 мы обязаны сравниваться с этими числами по сопоставимому
протоколу. Файлы сохранены, потому что результат в репозитории может измениться
или исчезнуть, а сравнивать надо с зафиксированной версией.

**Важно:** это самоописание авторов проекта. Независимой проверки этих чисел нет.
Собственные ограничения, которые авторы признают, — в разделе «Limitations» их
документации; краткая выжимка в [`../../01-audit.md`](../../01-audit.md).
